### Tabla resumen

| Componente     | Responsabilidad                                    |
| -------------- | -------------------------------------------------- |
| BrowserRouter  | Envuelve la app, conecta React al sistema de rutas |
| Routes + Route | Definen qué componente va con cada URL             |
| Link           | Navega sin recargar                                |
| Outlet         | Hueco donde se renderizan las rutas hijas          |
| Navigate       | Redirige desde código (útil en ProtectedRoute)     |
| useNavigate    | Hook para navegar desde funciones/eventos          |
| useParams      | Hook para leer parámetros dinámicos de la URL      |
| useLocation    | Hook para saber la ruta actual y su estado         |
